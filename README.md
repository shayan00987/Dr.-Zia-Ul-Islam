# Dr Zia Ul Islam: Website

Static, fully responsive website (HTML, CSS, JavaScript). No build step.

## Run it
Open `index.html` in a browser, or upload the whole folder to any web host (cPanel, Netlify, GitHub Pages, etc.).

## Structure
```
index.html          Main page (all sections)
css/style.css       Theme and responsive layout
js/main.js          Mobile menu, scroll reveal, 3 image slideshows
assets/             favicon + images/
```

## IMPORTANT: replace the placeholder images
The doctor's photo (`assets/images/dr-zia-ul-islam.jpg`) is real.
The other 16 images are labelled **placeholders** (each shows its filename and a suggested Pexels search).
Download suitable photos, save them with the **same filename** (`.jpg`) into `assets/images/`, and the site updates automatically. See `assets/IMAGE-GUIDE.md` for sizes and where each is used.

Rules kept: every image is a different file, and the three slideshows (The Practice, Beyond Surgery, Booking band) each use three different images.

## Content notes
All text is based on the doctor's Instagram profile (dr.zia.islam). No phone number, street address or fee amounts were invented. Add them in `index.html` (Locations / Costs sections) once the client supplies them.
Booking button links to the existing Acuity page.
